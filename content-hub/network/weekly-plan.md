# Professional Networking Weekly Plan

**Week of:** TBC  
**Primary outcome:** Create qualified conversations for BIM, CAD documentation,
design-to-site coordination, or construction project controls.

Activity targets below are planning targets, not claimed results. Log evidence after
each action and stop when the work would become generic or unverified.

| Day | Preparation | Manual platform action | Evidence to log |
|---|---|---|---|
| Monday | Select one proof-backed topic from the content hub | Publish or schedule one useful LinkedIn post after review | Post URL, pillar, and date |
| Tuesday | Review one target company or role from a legitimate source | Manually inspect the source and decide whether a connection is relevant | Source URL, fit reason, decision |
| Wednesday | Draft one substantive comment using the person's actual post | Manually review and publish if useful | Post URL, comment text, date |
| Thursday | Prepare one contextual connection note | Manually verify identity and send only with approval | Contact row and sent date |
| Friday | Review replies and open conversations | Manually respond; ask one qualifying question | Conversation note and next action |
| Sunday | Run `network_report.py` and review pipeline | Choose one next action per active contact | Report and updated due dates |

## Quality gate

- [ ] The action has a specific person, post, project, role, or company context.
- [ ] The draft contains no invented fact or unsupported metric.
- [ ] The draft is useful without pretending to know the recipient's private need.
- [ ] The user approved the final text before any send or publish action.
- [ ] The actual result is logged after the manual action.
