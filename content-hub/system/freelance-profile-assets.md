### Listing 1 — Revit model and drawing review

**Title:** I will review your Revit BIM model and drawing package

**Buyer problem:** The model or drawing set needs a focused independent check before
coordination, tender, or site use.

**Deliverable:** A review summary with identified coordination, documentation, and
information-quality issues based on the agreed package and review scope.

**Buyer must provide:** Project type, project stage, disciplines, file format,
package size, review deadline, and the specific decision the review must support.

**Boundary:** This is an information review, not statutory approval, a professional
design certification, or a replacement for the appointed design professionals.

### Listing 2 — CAD drafting and documentation support

**Title:** I will create or update architectural CAD drawings from your information

**Buyer problem:** Drawings need clean updates, consistent annotations, or additional
documentation capacity.

**Deliverable:** Agreed drawing sheets or updates produced from supplied sketches,
markups, dimensions, or reference files.

**Buyer must provide:** Base files, markups, dimensions, required sheet list,
standard or template, output format, and revision deadline.

**Boundary:** Scope excludes unprovided design decisions, site verification, and
professional sign-off unless separately agreed with the responsible professional.

### Listing 3 — Construction reporting and procurement tracker

**Title:** I will create a construction progress and procurement tracking system

**Buyer problem:** Project actions, procurement packages, or progress updates are
spread across messages and files without one clear view.

**Deliverable:** A tailored tracker and reporting structure based on the supplied
project information, reporting rhythm, and decision requirements.

**Buyer must provide:** Project phase, work packages, current reporting format,
procurement list, reporting frequency, and the people who will use the tracker.

**Boundary:** This is project-support administration and reporting; it does not
replace a project manager, quantity surveyor, contract administrator, or statutory
professional.
