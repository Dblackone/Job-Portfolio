# TikTok / Reels / Shorts Scripts

Three topics, each written at 30, 60, and 90 seconds. Same brand system, vertical format.

**Canvas:** 1080 × 1920 · top safe 250 px · bottom safe 320 px (caption, CTA, and UI) ·
on-screen text lives in the centred 920 × 1350 band. Full spec in `../BRAND.md`.

---

## Production rules

| Rule | Detail |
|---|---|
| **Hook in 2 seconds** | The first line must be spoken before the first frame finishes. No intros, no "hey guys", no name. |
| **Screen recording over face** | Roughly 70% screen capture, 30% talking head. The audience wants to see the software. |
| **Text on every frame** | Most viewers watch muted. On-screen text must carry the whole lesson. |
| **One idea only** | 30 seconds holds one idea. 90 seconds holds one idea explained properly. Never two. |
| **State the version** | Any Revit capture shows the version in the corner. |
| **No emoji** | Including in on-screen text and captions. |
| **No music with lyrics** | It competes with the voiceover and with muted reading. |
| **Cut on the beat of the sentence** | Every full stop is a cut. This alone doubles watch time. |
| **End on a question** | Comments drive distribution more than any other signal. |

**Recording setup:** screen capture at 1920 × 1080 then reframe to vertical, cropping to the
relevant panel — never scale the whole desktop down. Talking head shot at chest height, eyes
level with the top third, plain background, natural light from the front.

# TOPIC 1 — "It is not deleted"

The single most useful thing you can teach a Revit beginner. Highest save-rate topic in the
system.

**KB:** L1.11 · **Category:** Revit Basics

---

## 30-second version

| Time | Voiceover | On-screen text | Camera / Visual |

## Repurposing chain

Each 90-second script yields:

| Output | How |
|---|---|
| **60-second cut** | Drop the framing at the start and one supporting point |
| **30-second cut** | Hook, the single strongest idea, takeaway |
| **Instagram Reel** | Same file. Cover frame = dark hook card. |
| **YouTube Short** | Same file. Title = the on-screen hook, verbatim. |
| **LinkedIn video** | 60-second cut, with captions burned in. LinkedIn video is watched muted more than any other platform. |
| **WhatsApp Status** | Split the 90-second into three 30-second frames across three days |

**Never** post the same cut to two platforms on the same day. Stagger by 48 hours minimum.
